ЗАДАЧА: заполни поля узлов учебного слоя главы «$chapter_title». Для каждого узла ниже — его утверждения (это всё, что известно из книги).

ПОЛЯ (всё по-русски, коротко, фразы до 20 слов):
- topic — тема одной фразой; main — суть: 2–3 фразы, первая главное.
- mechanism — ПОЧЕМУ так: физика процесса или измерения. Используй ВСЕ утверждения узла, не теряй условий и чисел.
- practice — как это делает специалист: входные данные, порядок действий, пороги автора.
- nuances — условия применимости, оговорки автора, исключения, где правило ломается.
- deeper — 0–3 ветки «глубже» для любопытных (только из утверждений узла).
- misconception_ref — id заблуждения из списка ниже, если узел его исправляет; misconception_text — формулировка заблуждения (своё, если в списке нет подходящего; пусто, если узел заблуждение не исправляет).
- data_from_chapter — как это знание выглядит в данных (кривые, таблицы, числа): ТОЛЬКО прямо следующее из утверждений. data_breaks — где в данных правило даёт сбой (по главе). data_hypotheses — идеи для ИТ сверх главы (это гипотезы, 0–3 штуки).
- it_analogy — аналогия из мира данных и ИТ, понятная ML-инженеру; it_breaks_where — где аналогия перестаёт работать (обязательно).
- now_practice — если книга описывает устаревшие приборы, ручные палетки или методику, коротко: как это делается сейчас; иначе пусто.
- inefficiency — для практических узлов (процедура, интерпретация): входные данные, ручные шаги, точки суждения специалиста, время, типичные ошибки. Для чисто теоретических узлов — null.
- decision_on_data — если узел позволяет решение «признаки → правило → вывод» (с контрпримером), заполни; иначе null.
- to_data — датасеты, к которым ведёт узел: $datasets (только если связь прямая).
