ЗАДАЧА: построй план узлов учебного слоя главы «$chapter_title».

Узел — один шаг курса: одна законченная идея, которую можно объяснить и проверить. Узел = страница шага курса (5–10 минут чтения).

ПРАВИЛА:
- Каждое утверждение k… должно войти ровно в один узел. Ни одно не теряется.
- СКОЛЬКО УЗЛОВ: в этой порции $n_claims утверждений — сделай $nodes_min–$nodes_max узлов. Узел — законченная идея на 5–10 минут чтения (обычно 8–20 утверждений), а не одна-две фразы. Не дроби: соседние утверждения об одном и том же — в один узел. Делить узел стоит только если в нём явно две разные идеи.
- Порядок узлов — порядок, нужный новичку, а не обязательно порядок книги. Сначала то, без чего не понять следующее. why_here — почему узел стоит здесь.
- Ни один термин не используется раньше узла, где он объяснён: если узел пользуется термином (terms_used), узел, который его вводит (terms_introduced), стоит раньше.
- terms_introduced — только термины, которые узел действительно объясняет (обычно 1–4).
- terms_used — только СПЕЦИАЛЬНЫЕ термины предметной области, без которых мысль узла не понять и которые этот узел НЕ объясняет (обычно 0–5). Не пиши сюда общеупотребительные слова, общие научные понятия и термины, которые объяснены в другом узле этого плана, — их порядок программа проверит сама. Термины, которые глава не объясняет вовсе (они из предыдущих глав книги), тоже пиши сюда: для них будут созданы узлы-предпосылки.
- Один и тот же термин пиши везде одинаково, в именительном падеже, как в глоссарии: «потенциал собственной поляризации (ПС)».
- slug — латиница, цифры и _, уникальный.
- Тип трудности (основной и второй) — из восьми:
$difficulty_types
  Ожидаемые типы этой главы: $chapter_types.
- threshold = true только для 1–2 пороговых идей порции: без них дальше не понять, и они меняют взгляд на тему. У остальных узлов — false.
