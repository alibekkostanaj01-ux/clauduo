ЗАДАЧА: составь задания к шагам курса по главе «$chapter_title». Задания проверяют понимание, а не память на слова: «почему», «что будет, если», «какой вывод следует из данных», «где правило перестаёт работать».

ПРАВИЛА:
- Ответ на каждое задание ОБЯЗАН следовать из утверждений своего шага (они даны ниже). claim_ids — id утверждений, на которых держится ответ.
- На каждый шаг — 1–2 задания. Тип выбирай из разрешённых для шага (allowed). Старайся, чтобы в целом были все пять типов.
- single — один верный вариант из 3–4; multiple — 2–3 верных из 4–5; неверные варианты правдоподобны и, где можно, построены на заблуждении из списка (поле misconception = id заблуждения).
- order — 3–5 шагов процедуры или цепочки причин, которые в шаге стоят в определённом порядке; options — элементы, answer_order — их id в верном порядке.
- gap — фраза из шага с пропусками {{1}}, {{2}}: пропускается ключевое слово или число, которое однозначно восстанавливается по тексту шага; answer_gaps — пропущенные слова в нужной форме.
- calc — только если в шаге есть формула или числа, по которым считается ответ; answer_number — число, tolerance — допустимая погрешность, unit — единица; расчёт по данным автора, без новых чисел, которых нет в шаге.
- explanation — одна фраза: почему ответ верный (со ссылкой на мысль автора).
- kind: recall (узнавание), understanding (понимание), transfer (перенос на новую ситуацию), data (решение на данных).
- id вариантов: a, b, c, d, e.
