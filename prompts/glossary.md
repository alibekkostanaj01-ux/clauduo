$common

ЗАДАЧА: составь статьи глоссария доменного пакета для терминов, которые вводят узлы учебного слоя. Глоссарий общий для всех глав и нужен для курса (блок «Новые понятия»), поиска терминов в тексте и озвучки.

Для каждого термина:
- term — каноническая форма в именительном падеже, без скобок («потенциал собственной поляризации»).
- abbr — русское сокращение, если есть («ПС»), иначе пусто.
- aliases — другие написания и синонимы из текста (формы с сокращением, обозначения: «СП», «αпс»).
- definition — 1–2 фразы ТОЛЬКО по утверждениям ниже (это слова книги); числа — только из утверждений.
- claim_ids — id утверждений, на которые опирается определение (1–3 штуки).
- en — английский термин, принятый в западной литературе (это знание модели, оно будет помечено).
- symbol — обозначение величины в книге (Kп, ρп, ΔUсп), если это величина; symbol_en — западный аналог (φ, Rt, SP), если есть.
- stress — термин со знаком ударения U+0301 после ударной гласной в словах, где синтезированный голос может ошибиться (каро́таж); пусто, если ударение очевидно.
- say — как читать сокращение или обозначение вслух («пэ эс», «ка пэ»), по образцу словаря ниже; пусто, если не нужно.

Не выдумывай терминов, которых нет в списке. Если два термина из списка — одно и то же понятие, объедини их в одну статью (второе — в aliases).
